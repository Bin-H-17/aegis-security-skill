# Security Policy / 安全策略

## Reporting a Vulnerability / 报告漏洞

**English**
If you discover a security vulnerability in AegisKit, please report it
responsibly:
- Do NOT open a public GitHub issue.
- Email the maintainer (see the author in LICENSE) or open a **private** GitHub
  Security Advisory.
- Include a description, reproduction steps, and impact. You will receive an
  acknowledgment within 7 days.

Scope: vulnerabilities in AegisKit's own code. Issues in the third-party
scanners it invokes (semgrep, bandit, gitleaks, osv-scanner, pip-audit, reuse)
should be reported to their respective upstream projects.

AegisKit is a helper toolkit, not a guarantee of security — see DISCLAIMER.md.

**中文**
如发现 AegisKit 自身代码的安全漏洞，请负责任地报告：
- 请勿直接提公开 GitHub issue。
- 邮件联系维护者（见 LICENSE 作者信息）或提交 **私密** GitHub 安全公告。
- 请附描述、复现步骤与影响。我们将在 7 天内确认收悉。

范围：AegisKit 自身代码的漏洞。其调用的第三方扫描器（semgrep/bandit/gitleaks/
osv-scanner/pip-audit/reuse）的问题请上报各自上游项目。

AegisKit 是辅助工具，不构成安全保证，详见 DISCLAIMER.md。
